Executive Summary

CrowdStrike detected ransomware-related behavior on endpoint WKSTN-0482. The detection was triggered by a process tree showing cmd.exe spawning PowerShell with encoded commands targeting shared file resources. Investigation confirmed this is a True Positive requiring immediate containment.

Key Findings

  • Detection Source: CrowdStrike Falcon - Process Tree Analysis
  • Affected Host: WKSTN-0482 (10.42.16.89)
  • Threat Actor TTPs: T1486 (Data Encrypted for Impact), T1059.001 (PowerShell)
  • Lateral Movement: Confirmed - 3 additional hosts contacted via SMB within 4-hour window
  • IOCs Identified: 2 malicious hashes, 1 C2 domain (update-service[.]xyz)

Verdict

True Positive — Severity: High. Recommend immediate network isolation of WKSTN-0482 and forensic imaging. Escalate to Incident Response team.

Recommended Actions

  • Isolate endpoint WKSTN-0482 from the network immediately
  • Block C2 domain update-service[.]xyz at the perimeter firewall
  • Add identified hashes to CrowdStrike IOC block list
  • Scan 3 lateral movement targets for compromise indicators
  • Preserve forensic evidence and initiate IR playbook
